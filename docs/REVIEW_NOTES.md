# PRISM – Code Review

## Project Overview
PRISM is an LLM Gateway and Semantic Cache project.

## Project Structure

- `prism/` – Core application implementation.
- `tests/` – Test cases and verification.
- `scripts/` – Supporting scripts.
- `data/` – Configuration, model pricing and sample data.
- `docs/` – API contracts, data models and implementation documentation.

## Areas for Review

1. Application architecture and code organization.
2. LLM gateway implementation.
3. Semantic caching implementation.
4. API design and error handling.
5. Test coverage and code quality.

## Review Request

Please review the current PRISM implementation, focusing on the overall code structure, implementation quality, and areas for improvement.
